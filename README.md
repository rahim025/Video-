# VideoWall

Petite appli Android : choisis une vidéo, elle devient ton fond d'écran animé (muet, en boucle).

1. Mets ces fichiers sur GitHub (en gardant les dossiers).
2. Onglet **Actions** → **Build APK** → **Run workflow** (ou attends la fin du build après le push).
3. Ouvre le build terminé → **Artifacts** → télécharge **VideoWall-apk**, décompresse, installe `app-debug.apk`.
4. Ouvre VideoWall → choisis une vidéo → définis comme fond d'écran.
